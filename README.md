## What Glovium Is

Glovium is a roblox utility script that improves user experience _drastically_.  
We strive for great out-of-the-box ability, with the opportunity to push it further with user customisation.  
Reborn many times throughout the past few years, Glovium will be the final reconception. 

## What Glovium Aims To Do

Glovium aims to make the Roblox experience generally better, with general features that help with competitive games  
and great optimization, Glovium is a must have.  

At Glovium, we prefer **Undetectability Over Anarchy**. If you're looking for a script that will last you a few hours before getting banned, Glovium is not for you. Glovium aims to be subtle unlike most utilities in which it cannot be distinguished from usual gameplay. This comes with the caveat of being slightly less overpowered than we could've made it. That was an _intentional choice we made._ All issues that ask for a certain feature to be buffed to the amount where it is blatantly obvious, it will be closed. We do not do that.

If at any point you want to discuss game additions, please DM our lead developer on Discord `@invokexpression`.

## How do you use Glovium?

To use Glovium, open your executor and attach. Once attached, run the code below
```loadstring(game:HttpGet("glovium.aptfxx.dev"))```

As soon as you open, you will be asked for authentication. Glovium runs purely off the community and we strive for **zero keysystems or paywalls**. The only reason you may see this message is because we're currently in closed beta and Glovium must require a one time password to use.  
If you wish to test Glovium early, please DM our lead developer on Discord `@invokexpression` for inquires. Otherwise, stay tuned until Glovium fully releases to the public.
