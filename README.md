## What Glovium Is

Glovium is a roblox utility script that improves user experience _drastically_.  
We strive for great out-of-the-box ability, with the opportunity to push it further with user customisation.  
Reborn many times throughout the past few years, Glovium will be the final reconception. 

## What Glovium Aims To Do

Glovium aims to make the Roblox experience generally better, with general features that help with competitive games  
and great optimization, Glovium is a must have.  

At Glovium, we prefer **Undetectability Over Anarchy**. If you're looking for a script that will last you a few hours before getting banned, Glovium is not for you. Glovium aims to be subtle unlike most utilities in which it cannot be distinguished from usual gameplay. This comes with the caveat of being slightly less overpowered than we could've made it. That was an _intentional choice we made._ All issues that ask for a certain feature to be buffed to the amount where it is blatantly obvious, it will be closed. We do not do that.

## How many games does Glovium support?
Read from [/games](https://github.com/aptfxx/gloviumsrc/tree/main/games) or [gloviumdata.lua](https://raw.githubusercontent.com/aptfxx/gloviumsrc/refs/heads/main/gloviumdata.lua).

### How do I suggest a new game?
Glovium is actually run by contributors, if you want to suggest a new feature, open a github issue and your feature request could be added in a future update. The same goes for actual bugs you find in Glovium.

## How do you use Glovium?

To use Glovium, open your executor and attach. Once attached, run the code below
```loadstring(game:HttpGet('https://glovium.aptfxx.dev'))()```

Because we strive for **Zero Key Systems**, you will not need to open any other links for keys or payment. You'll instantly be greeted with the GUI for the game you're in (if supported), or a general universal script (for everything else)

## Fair Use Of Glovium
Glovium is obfuscated. This is to stop game developers from easily dumping our source code and patching exploits. However, actually trying to make the code readable isn't disallowed. You are allowed to dump the source, as long as you don't do the following:
- Selling Source
- Ripping off the source to make your own scripts (without reading below)
- Publishing modified copies of Glovium

### Attribution of source
If you end up using the source code of Glovium, you must request for permission by emailing `invokexpression@duck.com`.  
After being accepted, you must do the following before uploading:
- Adding glovium's repository in your README and description
- Make your script open source
- Add comments to the inspired parts attributing credit
- Emailing `invokexpression@duck.com` for review

### Legitimately obtaining source
If you wish to legitimately obtain the original source code, email `invokexpression@duck.com` explaining why.
